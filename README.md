# Wathiq — وثيق

نظام إدارة الوثائق والأرشفة الإلكترونية (ASP.NET Core MVC + MySQL + AdminLTE).

## التشغيل المحلي

```bash
cp appsettings.Development.json.example appsettings.Development.json
# عدّل كلمة مرور MySQL
dotnet run
```
