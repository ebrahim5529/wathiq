# سجل التطوير والتعديلات المنجزة — نظام وثيق للأرشفة الإلكترونية

**تاريخ التحديث:** 2026-11-05  
**المرجع:** `Docs/تحليل-نظام-الأرشفة.md`  
**التقنية:** ASP.NET Core 10 (MVC) + Entity Framework Core + MySQL + AdminLTE 4 RTL  

---

## 1. ملخص التطوير البرمجي الشامل (Full-Stack)

تم تحويل التصميم الأولي والقوائم الجانبية الثابتة إلى **نظام أرشفة إلكتروني متكامل وقابل للعمل الفعلي (Full-Stack)** يشمل كافة الشاشات والقوائم المحددة في وثيقة التحليل، مع ربط قاعدة البيانات، ومنطق إدارة وتخزين الملفات، ونظام الصلاحيات وسجل التدقيق.

---

## 2. تفصيل الملفات والتعديلات المنجزة

### أ) تطبيق أسلوب وتصميم الكروت من مرجع `adminite/index2.html` في كافة الشاشات
تم اعتماد نظام وتصميم البطاقات المتبع في قالب **AdminLTE 4 Dashboard v2** (`adminite/index2.html`) في جميع شاشات الموقع:
1. **صناديق المعلومات (`Info-Box`)**:
   - استخدام الـ `info-box` الأصلي ذي الأيقونات الملونة بالظلال `info-box-icon text-bg-... shadow-sm` مع `info-box-content` و `info-box-number`.
   - استخدام صناديق المعلومات ذات الخلفيات الكاملة الملونة (`info-box text-bg-warning / text-bg-success / text-bg-info`).
2. **أدوات البطاقات التفاعلية (`Card Tools`)**:
   - تزويد جميع البطاقات بأزرار الطي والتوسيع والإغلاق (`btn-tool` مع `data-lte-toggle="card-collapse"` و `data-lte-toggle="card-remove"`).
   - قوائم أدوات منسدلة داخل رأس البطاقة (`card-tools .dropdown-toggle`).
3. **أشرطة التقدم المتقدمة (`Progress Groups`)**:
   - استخدام `progress-group` مع `progress progress-sm` لعرض نسب المستندات والتخزين بجمالية عالية.
4. **تذييل البطاقات الإحصائي (`Card Footer Stats`)**:
   - استخدام التذييل المقسم لأعمدة إحصائية متساوية `card-footer bg-body` بتصميم نظيف بدون حدود جانبية فاصلة جهة اليسار/الشمال لإعطاء مظهر متناسق ومريح للعين.
5. **جداول البطاقات الصافية (`Card Body p-0 & Table m-0`)**:
   - جعل الجداول ممتدة إلى حواف البطاقة بدون هوامش ميتة مع تذييل نظيف للأزرار الإجرائية، وإزالة أي حدود رأسية جانبية (border-end/border-left) في كافة الشاشات والتقارير.

### ب) قاعدة البيانات والنماذج (`Models/` & `Data/`)

1. **`Models/ArchiveFile.cs`**:
   - إضافة دعم الحقول المتقدمة:
     - الطرف الثاني / الجهة (`Party`).
     - تاريخ المستند (`DocumentDate`) وتاريخ الانتهاء/الاستحقاق (`ExpiryDate`).
     - المبلغ المالي والعملة (`Amount`, `Currency`).
     - الوسوم (`Tags`) لتعزيز إمكانيات البحث.
     - علامة المفضلة (`IsFavorite`).
     - علاقة المشاركة مع جدول المشاركات (`Shares`).

2. **`Models/ArchiveFolder.cs`**:
   - إضافة خاصية التفضيل السريع (`IsFavorite`).
   - إضافة علاقة المشاركة (`Shares`).

3. **`Models/ArchiveShare.cs` (جديد)**:
   - نموذج لتنظيم مشاركة الملفات والمجلدات مع مستخدمين محددين أو أقسام كاملة، مع تحديد مستوى الصلاحية (`View`, `Download`, `Edit`).

4. **`Models/ActivityLog.cs` (جديد)**:
   - جدول سجل التدقيق ومسار النشاط (Audit Trail) لتوثيق كل حركة (رفع، تنزيل، تعديل، حذف، استعادة، مشاركة، إعدادات) متضمناً اسم المستخدم وعنوان الـ IP والتاريخ والتفاصيل.

5. **`Models/SystemSetting.cs` (جديد)**:
   - جدول لحفظ إعدادات المنظومة (الحصة التخزينية، الحجم الأقصى للرفع، الامتدادات المسموحة، أيام السلة، تنبيهات العقود).

6. **`Models/AppUser.cs` & `Models/AppRole.cs` (جديد)**:
   - إدارة المستخدمين وحساباتهم وحالتهم (نشط/معطل) وربطهم بالأقسام.
   - إدارة الأدوار الخمسة المعتمدة في التحليل: مدير النظام، أمين الأرشيف، مشرف قسم، موظف، وزائر.

7. **`Data/ApplicationDbContext.cs`**:
   - تسجيل الـ `DbSets` لجميع الجداول الجديدة.
   - ضبط الفهارس وعلاقات الربط المفتاحية وسياسات الحذف لمنع الأخطاء.

8. **ترحيل قاعدة البيانات (`Data/Migrations/20261105092254_FullSystemArchive.cs`)**:
   - إنشاء Migration رسمي يطابق جميع الجداول والحقول في قاعدة بيانات MySQL.

### ب) طبقة الخدمات (`Services/`)

1. **`Services/LocalStorageService.cs` (مطبق لـ `IStorageService`)**:
   - تخزين الملفات بمسار آمن ومعزول: `wwwroot/uploads/{yyyy}/{MM}/{guid}_{fileName}`.
   - منع ثغرات المسارات غير الآمنة (Path Traversal).
   - التحقق من الامتدادات المسموحة المحددة في النظام.
   - دعم تنزيل الملف باسمه الأصلي المحفوظ.
   - دعم تنزيل المجلد كاملاً بملف مضغوط **ZIP** مولد برمجياً.
   - حساب إجمالي المساحة المستهلكة من الحصة الكلية ونسبة الاستخدام.
   - الحذف الفيزيائي الفعلي للملف من القرص عند طلب الحذف النهائي.

2. **`Services/AuditLogService.cs` (مطبق لـ `IAuditLogService`)**:
   - تسجيل أحداث وعمليات المستخدمين تلقائياً مع التقاط الـ IP وسياق الطلب دون التأثير على استقرار التطبيق.

3. **`Services/DbInitializer.cs` (مطبق لـ `IDbInitializer`)**:
   - التزويد التلقائي (Seeding) عند أول تشغيل بقيم افتراضية واقعية تشمل:
     - 5 أقسام رئيسية (الموارد البشرية، الشؤون القانونية، المالية والمحاسبة، الإدارة التنفيذية، تقنية المعلومات).
     - 5 تصنيفات رئيسية بألوانها وأيقوناتها.
     - الأدوار والمستخدمين الافتراضيين.
     - مجلدات وملفات نموذجية لكل نوع مستند.
     - الإعدادات الأولية للنظام.

### ج) نماذج العرض (`ViewModels/ArchiveViewModels.cs`)

- **`FileManagerViewModel`**: لإدارة مجلدات الأرشيف، مسار التنقل (Breadcrumbs)، الملفات، شريط المساحة، والفلترة.
- **`DashboardViewModel`**: لإحصائيات لوحة التحكم، توزيع الأنواع، مؤشرات الأقسام، تنبيهات العقود القادمة، وسجل الأنشطة الأخير.
- **`SearchFilterViewModel`**: لفلترة البحث المتقدم عبر 10 معايير مختلفة.
- **`StorageReportViewModel`**: لتقارير استهلاك السعة حسب القسم والتصنيف والامتداد.

| **`FavoritesController`** | `/Favorites` | استعراض الملفات والمجلدات المفضلة مع إمكانية فتحها وتنزيلها وإدارتها. |
| **`RecentController`** | `/Recent` | عرض آخر 50 ملف تمت إضافتها أو تعديلها مع إمكانية التنزيل السريع. |

### هـ) واجهات العرض والقوالب (`Views/`)

1. **`Views/Shared/_Layout.cshtml`**:
   - ربط كامل شجرة القائمة الجانبية بالـ Controllers والإجراءات البرمجية الفعلية.
   - إضافة خاصية تمييز العنصر النشط (`active class`) وتوسيع القائمة المفتوحة (`menu-open`) ديناميكياً.
   - إضافة منطقة إشعارات ورسائل تنبيه علوية (`TempData["Success"]` و `TempData["Error"]`).
   - الحفاظ التام على تصميم `AdminLTE RTL` والوضع الداكن والفاتح.

2. **`Views/Archive/Index.cshtml`**:
   - واجهة مدير الملفات التفاعلية مع دعم العرضين (شبكي وقائمة).
   - نوافذ منبثقة (Bootstrap Modals) لـ:
     - رفع الملفات مع كافة البيانات التعريفية.
     - إنشاء مجلد جديد وتعيين قسمه.
     - إعادة التسمية السريعة للملفات والمجلدات.
     - مشاركة الملف أو المجلد وتحديد الصلاحية.
   - شريط مؤشر سعة التخزين التفاعلي.

3. **بقية الواجهات**:

### و) تهيئة التطبيق (`Program.cs`)

- تسجيل وحقن الخدمات:
  - `builder.Services.AddHttpContextAccessor()`
  - `builder.Services.AddScoped<IStorageService, LocalStorageService>()`
  - `builder.Services.AddScoped<IAuditLogService, AuditLogService>()`
  - `builder.Services.AddScoped<IDbInitializer, DbInitializer>()`
- تشغيل الترحيل التلقائي وتغذية البيانات الأولية (`DbInitializer.SeedAsync`) مع حماية من الأخطاء في حال كان الخادم غير متصل بقاعدة البيانات أثناء التطوير.
